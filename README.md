## How to Manually Update and Add Certificates
All certificate documents are stored directly in `assets/certificates/`. Each card in the Certifications section provides direct **"View"** (opens in new tab) and **"Download"** buttons.

### Replacing Existing Certificates:
Simply copy or overwrite the corresponding file in `assets/certificates/`:
- **AWS Academy**: `assets/certificates/aws-cloud-foundations.pdf`
- **IBM SkillsBuild**: `assets/certificates/ibm-ai-fundamentals.pdf`
- **Cisco AI Fundamentals**: `assets/certificates/cisco-ai-fundamentals.pdf`
- **TCS iON Soft Skills**: `assets/certificates/tcs-soft-skills.pdf`
- **LinkedIn Learning Ethics**: `assets/certificates/ethics-in-generative-ai.pdf`
- **Kushal Yuva Programme**: `assets/certificates/kushal-yuva-programme.pdf`

The website automatically serves your updated file on click and download immediately without needing any code changes.

### Adding a New Certificate:
**Method 1: Interactive On-Site Manager (Instant & No Coding)**:
1. Click the **"+ Add certificate"** button directly in the Certifications header on the website.
2. Fill in the Title, Issuer, Date, and Badge.
3. Upload your PDF / image or type the path.
4. Click **"Save certificate"** — the certificate is instantly rendered onto the page with working "View", "Download", and 3D tilt effects, and is saved in your browser.
5. Click **"Copy HTML code"** if you want to paste the exact static HTML block directly into `index.html`.

**Method 2: Static Source Update**:
1. Place your new PDF in `assets/certificates/` (e.g. `assets/certificates/my-new-cert.pdf`).
2. In `index.html`, duplicate one `<article class="cert-card tilt-card" data-tilt>` block under `#certifications`, updating the badge, title, issuer, and both button links (`href="assets/certificates/my-new-cert.pdf"`).

### Modifying Any Certificate:
- Click the **"Modify"** button directly on any certificate card.
- A dialog opens pre-filled with the certificate details.
- Edit the Title, Issuer, Date, Badge, or file link and click **"Update certificate"** to update it immediately.
